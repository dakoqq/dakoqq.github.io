Политика конфиденциальности

Дата вступления в силу: 11 июля 2026 г.

Данная Политика конфиденциальности описывает порядок обработки данных пользователей Telegram-бота для поиска фильмов по коду.

1. Собираемые данные

Бот может обрабатывать Telegram ID пользователя, имя пользователя и текстовые запросы, необходимые для выполнения поиска.

2. Использование данных

Данные используются исключительно для предоставления функционала поиска фильмов и обеспечения стабильной работы сервиса.

3. Передача данных

Данные не продаются и не передаются третьим лицам, кроме случаев, предусмотренных законодательством.

4. Безопасность

Администратор принимает разумные меры для защиты пользовательских данных.

5. Изменения политики

Политика может обновляться. Актуальная версия всегда доступна на данной странице.

6. Контакты

По вопросам работы бота обращайтесь к администратору через Telegram.
